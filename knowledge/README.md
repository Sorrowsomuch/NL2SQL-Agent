# DataAnalyze 知识库包

这是阶段三的第一版知识库骨架，目标是为后续字段语义理解、RAG 检索和智能选表提供可维护的数据基础。

当前这套知识库还没有接入执行链路，现阶段的作用是：

- 固化表用途、字段含义、关系提示、指标定义和常见问法
- 形成后续向量化与检索的稳定输入
- 让知识维护以文件形式进入版本管理，而不是散落在 prompt 里

## 目录说明

- `manifest.yaml`
  - 知识库包的总清单与约定
- `tables/`
  - 表级知识
- `columns/`
  - 字段级语义知识
- `relationships/`
  - 业务关系或 join 提示
- `metrics/`
  - 指标定义
- `patterns/`
  - 常见用户问法模式
- `glossary/`
  - 业务术语与别名

## 当前建议的向量化粒度

- 一个表条目一个向量
- 一个字段条目一个向量
- 一个关系条目一个向量
- 一个指标条目一个向量
- 一个问法模式一个向量

## 当前 embedding 约定

- 模型：`bge-m3`
- 语言：中文优先，兼容英文别名
- 适合内容：
  - 表用途
  - 字段真实含义
  - 业务口径
  - 常见问法

## 后续接入建议

后续接 RAG 时，建议按两段检索：

1. 先检索 `tables/ + metrics/ + patterns/`
2. 再根据候选表检索 `columns/ + relationships/`

这样比一次把所有字段说明全量喂给模型更稳。
