## 2026-05-14 后续任务书：Perfetto 双 Agent 接入

后续 Perfetto 不再只按模板分析推进，而是按原有数据库链路的双 Agent 思路演进：

```text
PerfettoExecutorAgent 生成 Perfetto SQL
 -> PerfettoTool 查询 output.pb
 -> PerfettoExecutorAgent 汇总指标和结论
 -> PerfettoReviewer 规则/LLM 审核
```
